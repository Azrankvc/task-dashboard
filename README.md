# Task & User Dashboard

A modern, responsive JavaScript application featuring a dynamic To-Do list with filtering capabilities and an asynchronous user fetcher from the Random User API.

## Features
- **Async/Await & Fetch API:** Fetches random user profiles dynamically with loading states and error handling.
- **Task Management (CRUD):** Add, complete, and delete tasks seamlessly.
- **Local Storage:** Saves tasks locally so your data persists across browser sessions.
- **Task Filtering:** Filter tasks between "All" and "Completed".

## Technologies Used
- HTML5 & CSS3
- Modern JavaScript (ES6+): `async/await`, `Array methods (map, filter)`, `LocalStorage`.
- Random User API
